# Lab Security Reports

This directory contains professional security assessment reports from authorized training labs and deliberately vulnerable course environments. Each report documents its scope, authorization, methodology, evidence, impact, and remediation recommendations.

## Available Reports

| Lab | Assessment | Findings | Report |
|---|---|---:|---|
| Hack Smarter Labs | Web Application Security Assessment | 11 | [View report](Hack-Smarter-Labs/README.md) |

## Repository Structure

Each lab is kept in its own directory:

```text
Reports/
├── README.md
└── Hack-Smarter-Labs/
    ├── README.md
    └── assets/
```

Future lab reports can be added as sibling directories and listed in the table above.

> All assessments in this collection must be limited to systems explicitly authorized for testing. Lab credentials, session tokens, and other sensitive material must not be published.
